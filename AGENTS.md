# HealingMart mandatory font policy
Read [global policy](https://github.com/healingmart/healingmart-cloudflare-guide-test/blob/policy/pretendard-20261028/FONT_POLICY.md) before UI/font/deploy changes. Default: self-hosted Pretendard Variable (SIL OFL 1.1) for Korean/English. Multilingual: only verified, self-hosted Noto Sans variants with license notice. No paid or unknown fonts; no explicit Malgun Gothic/맑은 고딕, Arial, Segoe UI, Apple SD Gothic Neo, Georgia, Times New Roman, Consolas; no CDN-only font dependencies. Install a fail-closed font audit in builds/deploys; do not deploy production or enable GitHub Actions for this change.
